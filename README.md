# Lightbox
Version 1.0.0 · 19 novembre 2026

Une table lumineuse pour décalquer un dessin sur papier, lettrer une bulle ou construire un décor en perspective sur iPad et iPhone.

A light table for tracing artwork on paper, lettering a speech balloon or drawing a background in perspective on iPad and iPhone.

[Ouvrir Lightbox / Open Lightbox](https://eigrutel.github.io/eigrutel-lightbox/lightbox.html)

## Français
Importe une image, cadre-la au doigt puis fige la table pour décalquer. Les guides fonctionnent aussi sur une table blanche. Le dessin est traité dans le navigateur.

## English
Import an image, position it with your fingers and freeze the light table to trace. Lettering and perspective guides also work on a blank table. The image is processed locally in the browser.

## Installation
Ouvre `lightbox.html` dans un navigateur. Pour héberger l’application, copie les fichiers à la racine du site en conservant le dossier `favicon/`.

Open `lightbox.html` in a browser. To host the app, copy the files to the site root and keep the `favicon/` directory alongside them.
