A light table for tracing artwork on paper, lettering a speech balloon or drawing a background in perspective on iPad and iPhone.

Ouvrir Lightbox / Open Lightbox Code source / Source code Version stable / Latest release

Utilisation

Importe ton dessin, ajuste sa taille et touche Figer avant de poser la feuille. Pour travailler sur fond blanc, ouvre directement les guides de lettrage ou de perspective.

Getting started

Import your drawing, adjust its size and tap Freeze before placing paper on the screen. For a blank light table, open the lettering or perspective guides directly.
